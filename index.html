About This Project

This website was prepared as part of a Social Internship in the Web Development domain. The objective was to demonstrate how AI-assisted website development can help local educational institutes establish an informative digital presence.

The project involved requirement gathering, website planning, content organization, manual customization, responsive testing, and documentation for the Badarpur franchise of Orane International Beauty & Wellness Academy.

⚠ Academic demonstration only — not the official Orane International website

How This Website Was Built

Development process

The steps followed while preparing this Social Internship demonstration project.

1

Requirement Gathering

Understanding the academy's courses, facilities and communication needs.

2

Academy Visit

Visiting the Badarpur campus to observe facilities and collect reference photographs.

3

Content Collection

Gathering accurate course, contact and facility details for the website.

4

Website Planning

Mapping out pages, navigation and the overall visual identity.

5

AI-assisted Website Generation

Using AI tools to scaffold the initial HTML, CSS and JavaScript structure.

6

Manual Customization

Reviewing and editing content, layout and imagery to reflect the real academy.

7

Testing & Review

Checking responsiveness, accessibility and content accuracy across pages.

8

Final Demonstration

Preparing the completed website and report for internship submission.
